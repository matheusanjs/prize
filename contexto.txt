Análise Completa do Projeto Prize Clube 🚤
Visão Geral
O Prize Clube é um sistema completo de gestão de clube náutico/marina com múltiplos frontends, backend API, banco de dados relacional e integrações com serviços externos. O domínio de produção é marinaprizeclub.com.

Infraestrutura e Integrações
Banco de Dados: PostgreSQL 16 (Prisma ORM) — ~40+ models/tabelas
Cache/Filas: Redis 7 (BullMQ para jobs assíncronos)
Documentação API: Swagger em /api/docs
Segurança: Helmet, CORS restrito, Throttler (rate limit), JWT, bcrypt
Push Notifications: APNs (iOS), Web Push (PWA), com tracking de eventos
Pagamentos: Woovi (PIX com QR code)
IA: Google Generative AI + OpenAI (chat, insights, geração de conteúdo)
WhatsApp: Baileys (conexão direta, sem API oficial)
Meteorologia: Stormglass API + HGBrasil
PDF: PDFKit (geração de PDFs)
Processos: PM2 com configuração hardened para produção

Observações e Possíveis Melhorias Identificadas
ecosystem.config.js tem module.exports duplicado — a segunda definição (linhas 77-139) sobrescreve a primeira (linhas 14-76), perdendo configurações avançadas (autorestart, watch, max_restarts, logs)
shared/types tem divergências com o schema Prisma (enums como BoatStatus.ACTIVE vs Prisma AVAILABLE, ReservationStatus com campos diferentes, interfaces com campos que não existem no schema)
garcom é um app muito simples (apenas login + page principal) — pode estar incompleto
